# Assignment 11: Building First Dataset

## Overview
An introduction to creating and working with your first dataset from scratch.

## Purpose
Demonstrates how to build a dataset, understand its structure, and prepare it for analysis.

## Contents
- `main.py` - Python script for dataset creation and exploration
- `dataset.txt` - Raw dataset file
- `README.txt` - Documentation

## Concepts Covered
- Dataset creation
- Data structure design
- CSV/text file handling
- Data validation

## Learning Objectives
- Understand dataset components
- Learn data collection methods
- Practice data organization
- Prepare data for analysis
