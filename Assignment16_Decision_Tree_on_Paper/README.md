# Assignment 16: Decision Tree on Paper

## Overview
A manual exercise in understanding decision tree algorithms by building one on paper.

## Contents
- `decision_tree.txt` - Hand-drawn or documented decision tree structure

## Purpose
Understand how decision trees work by manually creating one without code.

## What You'll Learn
- Tree structure and nodes
- Decision rules and splits
- Leaf nodes and predictions
- Information gain and entropy concepts
- How algorithms choose split points

## Concepts Covered
- Decision tree fundamentals
- Classification logic
- Tree-based reasoning
- Manual algorithm walkthrough

## Real-Life Applications
- Medical diagnosis
- Credit approval
- Customer segmentation
- Feature importance analysis

## Next Steps
After understanding the manual process, implement decision trees using scikit-learn.
