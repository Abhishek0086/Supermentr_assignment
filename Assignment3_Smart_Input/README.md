# Assignment 3: Smart Input

## Overview
A program that takes user input and provides personalized messages based on age categorization.

## Features
- Takes user input for name, age, and hobby
- Categorizes age into groups (Child, Teenager, Adult, Senior)
- Generates personalized messages based on input

## Age Categories
- **Child**: Less than 13 years
- **Teenager**: 13-19 years
- **Adult**: 20-59 years
- **Senior**: 60+ years

## Usage
```bash
python Smart_Input.py
```

Enter your name, age, and hobby when prompted to receive a personalized message.

## Example Output
```
Hello John!
You are 25 years old, which makes you an Adult.
It's awesome that you enjoy coding!
```

## Concepts Covered
- User input handling
- Conditional statements (if-elif-else)
- String formatting
