# Assignment 5: Student Data Manager

## Overview
A comprehensive student management system that collects student data, calculates statistics, and assigns grades.

## Features
- **Data Collection**: Input student names and marks
- **Grade Assignment**: Automatic grading based on marks
- **Statistics**: Calculate class average, identify topper and lowest scorer
- **Summary Report**: Display all results with grades

## Grade Scale
- **A+**: 90 and above
- **A**: 75-89
- **B**: 60-74
- **C**: 50-59
- **F**: Below 50

## Usage
```bash
python Student_Data_Manager.py
```

Enter the number of students and their details when prompted.

## Output
- Individual student marks and grades
- Class average
- Topper information
- Lowest scorer information

## Concepts Covered
- Lists and dictionaries
- Lambda functions
- Data aggregation and analysis
