# Assignment 7: Dataset Detective

## Overview
An exploratory data analysis (EDA) tool that investigates and summarizes dataset characteristics.

## Features
- **Display Data**: Show first 5 rows of the dataset
- **Find Highest Value**: Identify the column with the maximum value
- **Missing Values**: Count and display missing data
- **Dataset Info**: Show data types and structure
- **Summary Statistics**: Display descriptive statistics

## Requirements
- Python 3.x
- Pandas library

## Installation
```bash
pip install pandas
```

## Usage
```bash
python Dataset_Detective.py
```

Ensure `student_data_simple.csv` is in the same directory.

## Output Includes
- First 5 rows of data
- Column with highest value
- Missing value counts
- Data types and non-null counts
- Mean, median, std dev, min, max for numeric columns

## Concepts Covered
- Pandas DataFrames
- Data exploration techniques
- Statistical analysis
- Data quality assessment

## Dataset Format
CSV file with student data including numeric and categorical columns.
