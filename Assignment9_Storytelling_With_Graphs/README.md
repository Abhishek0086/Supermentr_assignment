# Assignment 9: Storytelling With Graphs

## Overview
A data visualization project that creates multiple chart types to tell stories with sales data.

## Features
- **Bar Chart**: Shows monthly sales trends
- **Pie Chart**: Displays sales distribution percentages
- **Histogram**: Visualizes sales frequency distribution

## Requirements
- Python 3.x
- Pandas library
- Matplotlib library

## Installation
```bash
pip install pandas matplotlib
```

## Usage
```bash
python Storytelling_With_Graphs.py
```

Ensure `sales_data.csv` is in the same directory.

## Expected Output
Three visualization windows will open showing:
1. Monthly sales as a bar chart
2. Sales distribution as a pie chart
3. Sales frequency as a histogram

## Dataset Format
CSV file with columns:
- `Month`: Month name
- `Sales`: Sales value

## Concepts Covered
- Data visualization
- Matplotlib plotting
- Chart types and their use cases
- Data storytelling

## When to Use Each Chart
- **Bar Chart**: Compare values across categories
- **Pie Chart**: Show proportions of a whole
- **Histogram**: Display distribution of continuous data
